# Scope rule (see README.md): every RFC published by the IETF OAuth WG; OAuth's
# origin (RFC 5849); every RFC that formally Updates an OAuth WG RFC; the JOSE
# core that OAuth/OIDC tokens are built on; and every RFC that
# oauth-openapi.yaml cites. Everything else OAuth-related is catalogued in
# ../audit/rfc-coverage-audit.md but deliberately not vendored.
